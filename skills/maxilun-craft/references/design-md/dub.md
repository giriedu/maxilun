# Dub Design System Analysis

## 1. Core Principles
- **High-Craft Light-Mode SaaS**: Proves that modern developer/marketing tools do not need dark mode to look sharp. Uses `#ffffff` cards with `1px solid #e5e7eb` borders, `8px–12px` radii, and subtle `0 1px 2px rgba(0,0,0,0.04)` elevation.
- **Inline Analytics Pills**: Each link row displays its short link, destination URL with favicon, a copy button, and a live click-count badge (`tabular-nums`) with a mini sparkline tooltip on hover.
