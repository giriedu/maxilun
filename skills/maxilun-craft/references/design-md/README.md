# Design Reference Corpus

This directory is a bundled reference library for `maxilun-craft`. It contains 100 design analyses covering product interfaces, editorial systems, commerce, mobility, finance, developer tools, AI platforms, and brand-led visual systems.

## How to use it

1. Read the project brief and identify the audience, primary task, surface type, and platform.
2. Select at most two references with a comparable problem or visual constraint.
3. Extract principles: hierarchy, type scale, spacing rhythm, color roles, component density, interaction behavior, or motion restraint.
4. Translate those principles into the project's own tokens and content. Do not copy names, logos, screenshots, or brand identity.
5. Record the selected files, applicable principles, rejected principles, and the reason for each choice.

## Selection rules

- Prefer problem similarity over brand popularity.
- Use one reference for structure and one only when a second reference adds a distinct, necessary constraint.
- Do not combine unrelated references into a visual collage.
- If no reference fits, say so and derive the system from product context instead of forcing a match.
- A reference is evidence for a design decision, not an instruction to reproduce a brand.

## Expected note

```text
References: <file names>
Applied: <principles translated into this product>
Rejected: <principles not suitable here>
Reason: <audience, task, platform, or brand constraint>
```
