# Maxilun Network References Index

Indeks pustaka rekayasa jaringan, router MikroTik RouterOS, firewall Linux, dan infrastruktur enterprise.

## Berkas Referensi Domain

1. **`mikrotik-routeros-playbook.md`**:
   Aturan arsitektur MikroTik RouterOS v6 & v7, filter firewall stateful default-drop, NAT & hairpin NAT, pembagian bandwidth PCQ / Queue Tree, bridge VLAN filtering, WireGuard, dan scripting otomatisasi RouterOS.
2. **`enterprise-linux-networking.md`**:
   Routing multi-WAN kebijakan `iproute2` (`ip rule`), firewall deklaratif `nftables`, diagnostik socket `ss` dan `tcpdump`, serta penanganan MTU/MSS clamping terowongan VPN.

## Panduan Pemuatan
- Tugas konfigurasi MikroTik RouterOS, WinBox, script .rsc, hotspot, atau routing MikroTik → baca `references/mikrotik-routeros-playbook.md`.
- Tugas Linux network, nftables, policy routing, wireguard server, atau analisis paket → baca `references/enterprise-linux-networking.md`.
