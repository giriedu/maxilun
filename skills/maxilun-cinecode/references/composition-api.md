# Remotion Composition Guide

This is a Maxilun orientation guide to the official Remotion runtime, not a custom video API. Follow the installed Remotion version and the official `remotion-best-practices`, `remotion-create`, and `remotion-markup` skills when present. Consult current [Remotion documentation](https://www.remotion.dev/docs) for APIs that are not shown here.

## 1. Composition, frame, and scene

A Remotion video is a React component rendered at discrete frames. Register compositions using Remotion's `<Composition>` in the project root. A scene can use a `<Sequence>` to position it on the timeline; its child `useCurrentFrame()` starts at the scene's local frame 0.

```tsx
import React from 'react';
import {
  AbsoluteFill,
  Composition,
  Sequence,
  interpolate,
  spring,
  useCurrentFrame,
  useVideoConfig,
} from 'remotion';

const TitleScene: React.FC<{ title: string }> = ({ title }) => {
  const frame = useCurrentFrame();
  const { fps } = useVideoConfig();
  const entrance = spring({ frame, fps, config: { damping: 20, stiffness: 140 } });
  const opacity = interpolate(frame, [0, 12], [0, 1], {
    extrapolateLeft: 'clamp',
    extrapolateRight: 'clamp',
  });

  return (
    <AbsoluteFill style={{ justifyContent: 'center', padding: 100, backgroundColor: '#f1eee6' }}>
      <h1 style={{ margin: 0, opacity, transform: `translateY(${(1 - entrance) * 36}px)`, fontSize: 92 }}>
        {title}
      </h1>
    </AbsoluteFill>
  );
};

const VideoComposition: React.FC = () => (
  <AbsoluteFill>
    <Sequence from={0} durationInFrames={90} name="Title">
      <TitleScene title="One clear idea" />
    </Sequence>
  </AbsoluteFill>
);

export const RemotionRoot: React.FC = () => (
  <Composition
    id="Main"
    component={VideoComposition}
    durationInFrames={90}
    fps={30}
    width={1920}
    height={1080}
  />
);
```

Use the root component and file names generated by the project's official template. The example illustrates frame timing only; always replace its text and styling with the approved brief.

## 2. Timing and composition patterns

- Use `useCurrentFrame()` and `useVideoConfig()` from `remotion`; pass frame and fps into `spring()` or use `interpolate()` for explicit timing.
- Use `<Sequence>` for positioned clips/scenes. Use `<Series>` for adjacent scenes whose positions should follow their durations. Use `<TransitionSeries>` and its transition package only when the edit calls for a designed transition.
- Use `calculateMetadata()` when the composition duration, dimensions, or fps depends on input props. Keep claims, data, and asset paths in explicit props or project files.
- Never use CSS transitions, `setTimeout`, or `requestAnimationFrame` to animate rendered frames. Avoid unseeded randomness and browser state that changes pixels independently of the current frame.
- Match animation duration and hold time to reading speed and the edit; there is no mandatory scene count, hook formula, stagger, or amount of movement.

## 3. Video, audio, image, and font assets

- Put project-owned assets in the Remotion project's `public/` directory and address them with `staticFile()` where appropriate.
- Use `<Video>` and `<Audio>` from `@remotion/media`, and `<Img>` from `remotion`, when their documented behavior fits the edit. Prefer `delayRender()`/`continueRender()` for asynchronous assets that must be ready before a frame is captured.
- Treat an AI-generated clip as source footage. Do not ask text in a video-generation prompt to render precise titles, captions, UI labels, or charts; composite those as Remotion graphics.
- Keep audio, captions, and visual cuts aligned to the same timeline. Generate captions from final narration/transcript when requested; do not invent spoken text.

## 4. Studio, preview, and render

Start the interactive preview with the project's `npm run dev`. Use Remotion Studio to review framing, title safety, motion, cuts, footage continuity, and audio sync while building. Keep the preview open when the client supports it.

Render only when the user requests an export or the task clearly includes delivery of a video file. Use the project's installed Remotion CLI and the actual composition ID, for example:

```bash
npx remotion render Main ./out/video.mp4
```

Choose output format, codec, dimensions, and quality from the requested destination and current Remotion docs. Do not use the legacy `scripts/render.js` or hand-maintained FFmpeg pipeline for a new Remotion project.
