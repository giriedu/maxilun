# Architecture Decision Records (ADR)

Direktori ini mencatat keputusan arsitektural penting pada proyek Maxilun.
Setiap keputusan signifikan dibuat menggunakan format standar dari skill `maxilun-architect`.

## Format ADR

```markdown
# ADR-{N}: {Judul}

**Status**: Proposed | Accepted | Rejected | Deprecated | Superseded by ADR-{M}
**Tanggal**: YYYY-MM-DD
**Pembuat**: {Nama / Arsitek}

## Konteks
Situasi teknis dan bisnis yang melatarbelakangi kebutuhan keputusan ini.

## Opsi yang Dievaluasi
- **Opsi A**: {Deskripsi} — Pro: ..., Kontra: ...
- **Opsi B**: {Deskripsi} — Pro: ..., Kontra: ...

## Keputusan
Opsi yang dipilih beserta justifikasi berbasis matriks evaluasi arsitektural.

## Konsekuensi
Trade-off yang diterima, dampak terhadap sistem, dan apa yang harus diantisipasi tim.
```
